# Python Engineering

Python is a transversal skill for cloud automation, APIs, testing and operational tooling.

## Learning sequence
1. Syntax, types, control flow and functions
2. Collections, files, exceptions and modules
3. Virtual environments, packaging and dependencies
4. HTTP APIs, JSON and authentication patterns
5. CLI automation and cloud SDKs
6. Logging, unit tests, type hints and quality checks

The first utility validates IPv4/IPv6 subnet plans and detects overlaps before cloud deployment. See [Python Lab 001](README-LAB-001.md).
