# AWS Labs

Focus: IAM, VPC, EC2, S3, RDS, load balancing, Route 53, CloudWatch, backup and cost controls.

## Lab sequence
1. Account safety and IAM least privilege (planned)
2. VPC with public/private subnet design (planned)
3. Secure compute and storage (planned)
4. Monitoring and alerting (planned)
5. Resilient multi-AZ reference architecture (planned)

Use a sandbox account, MFA, budgets and short-lived credentials. Prefer IAM Identity Center or OIDC rather than long-lived access keys.
