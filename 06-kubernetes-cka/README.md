# Kubernetes and CKA

Hands-on Kubernetes administration using a local disposable cluster first, then a sandbox environment.

## Learning sequence
- Cluster architecture, API objects and kubectl
- Workloads, scheduling, probes and resource management
- Services, DNS, ingress and network policies
- Storage, volumes and persistent claims
- RBAC, service accounts and security contexts
- Troubleshooting nodes, control plane and workloads
- Backup/restore concepts and cluster maintenance

Record the Kubernetes version and distribution tested in every lab. Do not assume an employer's cluster version or distribution; validate it with authorization before any workplace-specific learning.
