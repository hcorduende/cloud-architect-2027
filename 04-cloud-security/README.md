# Cloud Security

Security is embedded in every track, not postponed to a final phase.

## Learning areas
- Identity, federation, MFA, RBAC and least privilege
- Cloud security posture management and policy
- Network segmentation, private connectivity and WAF
- Data classification, encryption and key management
- Logging, detection, incident response and threat modeling
- Secure software supply chain and secrets management

For each control, document the threat, preventive/detective response, evidence and residual risk.
